# 数据格式与评分方法

本文档说明 `data.js` 的字段规范与 V0 评分公式，供二次开发时参考。

仓库自带独立的数据更新脚本 `scripts/update-data.mjs`，不依赖任何私有平台；但央行公告与银行间利率没有稳定的开放 API，这部分仍需手工录入（见第 1 节与 README「自己更新数据」）。

## 1. 数据从哪里来

本仓库**不包含服务端数据抓取服务**。`data.js` 是一份静态快照（当前为 2026-11-06）；仓库提供独立脚本 `scripts/update-data.mjs` 供本地手动更新，页面本身只读这个文件。

GitHub 定时任务北京时间工作日 09:25、10:30，每天 16:30、18:23 运行 `scripts/auto-market.mjs`，仅更新 `market` 盘中累计或收盘成交额，再构建部署。早盘必须取得当天两市时间戳与有效成交额，否则跳过；盘中明确标注与前日全天不可直接比较。16 点后取两市实际日线与前日全天基准。`market.date` 是行情实际交易日期，不等于流动性数据日期 `date`。央行、利率、趋势和日历因素仍需人工核对；行情更新不会改变这些字段或归档评分。数据源失败则保留原文件，任务报错。

快照中的指标来自公开渠道：

| 字段组 | 内容 | 来源性质 | 更新方式 |
|---|---|---|---|
| `ops` | 央行公开市场操作（操作量、到期量、品种） | 中国人民银行公开市场业务交易公告 | 手工录入 |
| `policyRate` / `dr001` / `dr007` / `r001` / `r007` | 政策利率与银行间资金利率 | 公开市场行情 | 手工录入 |
| `market.amount` | 沪深两市成交额 | 公开行情接口 | 脚本拉取 |
| `marketStats` 的指数涨跌 / 主力资金 | 当日大盘表现 | 公开行情接口 | 脚本拉取 |
| 实时行情与分钟成交额 | 页面内 JSONP 请求 | 第三方公开接口 | 浏览器端 |

> 第三方行情接口可能变更或拒绝跨域请求；页面对此做了超时与失败兜底，但**不保证可用性**。使用者需自行确认数据来源方的使用条款，本仓库不分发历史行情数据。更新脚本在行情拉取失败或数值越界时**拒绝写入任何文件**。

## 2. data.js 字段规范

顶层：`window.PBEC_DATA = { ... }`，单位：利率 %、利差 bp、金额 亿元。

| 字段 | 类型 | 说明 |
|---|---|---|
| `date` | string | 快照日期 `YYYY-MM-DD` |
| `rev` | number | 同一天内修正数据时 +1，用于强制页面重新采纳 |
| `policyRate` | number | 主要政策利率 |
| `termPremium` | number | 政策利率之上的期限溢价（bp），当前为经验设定值 10 |
| `dr001` / `dr007` / `r001` / `r007` | number | 资金利率读数 |
| `chg001` / `chg007` | number | 较 5 个交易日前的 bp 变化，负 = 回落 |
| `factors` | object | 日历扰动勾选：`tax` / `monthEnd` / `quarter` / `festival` / `bond` / `fiscal` |
| `ops[]` | array | 最近 5 个交易日操作流水 `{date, type, amt, due}`；`amt` = 投放，`due` = 当日到期 |
| `market` | object | `{date, amount, prevAmount, prevDate, source}` |
| `history[]` | array | 历史快照，最多 30 条、按日期倒序；`estimate:true` 表示分数是按当前模型**回算**，非当日实算 |
| `marketStats[]` | array | 流动性状态 → 当日大盘表现样本，最多 120 条、按日期升序 |

页面会在首次加载时把 `data.js` 采纳为基准样本；同一天内若数据内容变化（或 `rev` 递增），会按内容签名重新采纳，但不会覆盖用户手工调整的参数。页面自动生成的归档样本按「日期 + 评分口径」分组保存在浏览器 `localStorage` 中，**权威样本始终来自 `data.js`**。

## 3. V0 评分公式

四模块加权，总分区间 0–100：

```
操作分   = clamp(15 + 近 5 日累计净投放 / 600, 0, 30)
价格分   = clamp(20 - (DR007 - (政策利率 + 期限溢价 10bp)) * 100, 0, 40)
趋势分   = clamp(10 - (chg007 + chg001) / 4, 0, 20)
特殊因素 = 5 + 扰动调整
           税期 -2 / 月末 -1 / 季末 -1 / 春节前 -3 / 政府债高峰 -2 / 财政支出 +2
```

**判定档位（页面 `verdictOf`，五档）**：`>= 80` 明显宽松 · `60–79` 偏松 · `40–59` 中性 · `20–39` 偏紧 · `< 20` 明显偏紧。

「流动性状态 → 大盘表现」统计器另按**三态**分组（`>= 60` 宽松 / `>= 40` 中性 / 其余偏紧），与页面显示的五档不是同一套划分。

页面另提供「数量优先 / 价格优先」两种权重口径（默认 `30/40/20/10`，价格优先 `15/50/25/10`），切换后样本分开归档，不混在同一条曲线上。

## 4. 已知未校准项（重要）

这套系数是**经验设定，未经统计校准**，请在把分数用于任何决策前先了解：

1. 操作分的分母固定为 600 亿，净投放到约 ±9000 亿即触顶，多数交易日该模块接近饱和或归零，实际区分度很低。
2. `termPremium = 10bp` 是人为设定；实际 DR007 与 DR001 的期限结构可能明显不同，改变该值会直接改变判定档位。
3. `history` 中 `estimate:true` 的条目是用**当前**模型回算的历史值，与当时实算值不可直接比较。
4. 「流动性状态 → 大盘表现」是**同步统计，不是预测**：两者互为镜像，相关性不等于因果；样本少于 5 天的状态组页面不给结论。
5. 当前快照只有 1 条市场表现样本，且是 11:30 盘中数据，与「前一交易日全天」口径不完全一致。
6. `amountChg`（成交额同比）需要「前一交易日同一时段」的分钟口径，独立更新脚本不推算该值，归档时留空。

## 5. 本地运行

- 直接双击 `dist/online.html`：单文件、已内联数据，离线可看（实时行情请求会失败并回退）。
- 开发时双击 `liquidity-dashboard.html`：读取同目录 `data.js`。
- 重新构建：`npm run build`（把 `data.js` 内联进源码并生成 `dist/` 三件套）。
- 回归测试：`npm test`（覆盖评分、样本迁移、空值覆盖、归档日期、口径分组、同日修正；期望值从快照动态读取，更新数据后仍成立）。
- 离线自检：`npm run check`（不联网，校验 `data.js` 结构与评分一致性，CI 每次都会跑）。
- 更新数据：`cp data/manual-input.example.json data/manual-input.json` 填写手工字段后运行 `npm run update`；加 `-- --dry-run` 只看变更计划。脚本会复用页面自身的 `computeScore()` 复算评分，不引入第二套公式。
